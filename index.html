How an engagement runs

Short cycles, visible progress, and nothing you can’t see or take with you.

  1. First, we listen.

    Workshops to map your systems, data and the problem worth solving first.

  2. Then we cost it.

    A costed plan with monthly milestones, so you know what you’re approving.

  3. Each month, a demo.

    Working software every month, shown in a demo before you’re invoiced.

  4. Then we stay.

    Support, monitoring and improvements, with the code and data always yours.
