Senior backend engineer, data and AI

Beyond Zenith is hiring a senior backend engineer in Indonesia with strong data engineering skills. You start on an Australian insurance-technology platform, work across its products, and grow with us as we add clients. Your work goes to production and people use it every day.

Remote, Indonesia · Full-time contractor

Apply on LinkedInAll roles

About Beyond Zenith

Beyond Zenith builds and runs software for Australian businesses. Our clients own their code, data and cloud accounts from day one. We work as dedicated delivery teams, build data and integration platforms (mostly on AWS), and give independent architecture and delivery advice. Clients see working software often, and we stay engaged after go-live so their systems keep performing. Our model is senior engineers across the region, led locally in the client’s time zone. We use AI in everything we do, from discovery to code to operations.

You join early. You help decide how we build, which tools we use and how we work with clients, and you grow with the company as we add clients and products.

The role

You are a senior backend engineer at Beyond Zenith first. You bring strong engineering skills, learn new domains fast and use AI to deliver more. Your first focus is data and AI work for our insurance-technology client, and you move across clients and products as the business grows. You work with our tech lead, the team in Indonesia and the founder in Melbourne.

What you will do

  • Design, build and run backend services and APIs on AWS.
  • Build and run data pipelines and integrations: ingestion, transformation, data quality and matching.
  • Build AI features with LLMs, such as document extraction and workflow automation, and measure how well they work.
  • Work with clients to turn unclear needs into a plan and working software.
  • Write short design decisions, review code and demo your work to clients.

Must-have skills

  • 5+ years as a backend or data engineer, with production systems you built and ran.
  • Backend: strong Python, API design (REST), testing, and a backend framework such as FastAPI or Django.
  • Data engineering: strong SQL (PostgreSQL), data pipelines and ETL, layered data models (medallion or similar), data quality and entity matching.
  • AWS serverless: Lambda, Step Functions, S3, RDS/Aurora or Athena, IAM, CloudWatch, and CI/CD with GitHub Actions. Infrastructure as code is expected.
  • LLMs in production: you have used an LLM (Bedrock, OpenAI, Anthropic or similar) to turn documents or data into structured output, with JSON schemas and a way to measure accuracy.
  • Clear written and spoken English. You work with Australian clients every week.

Nice to have

  • Salesforce data model and APIs, or AWS AppFlow.
  • BI dashboards (QuickSight, Power BI or similar).
  • AI coding tools in daily use (Claude Code, Kiro, Cursor or similar).
  • Work for an agency or consultancy with several clients.
  • Any AWS certification is a big plus.

Hiring process

  1. CV and short-answer review

  2. 30-minute intro call with the founder

  3. 60-minute technical interview with the tech lead

    Live Python and SQL, plus a data design question.

  4. Short take-home

    Extract structured data from sample documents and show how you measure accuracy.

  5. Reference check and offer

We reply to every applicant within 2 weeks.

How to apply

Apply on LinkedIn with your CV. In a few lines, tell us about one data pipeline or AI extraction system you built: what it did, its size, and what you would change now. A GitHub link or code sample helps.
